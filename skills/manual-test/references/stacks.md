# Признаки стека, типы продукта и механизмы моков — manual-test

Справочник к шагам 0 и 5 скилла manual-test: по каким признакам определить стек и тип продукта
и где искать механизм самого проекта для симуляции внешних сервисов и редких состояний.

## Стек и тип продукта (шаг 0)

- **Стек — по манифесту в корне** (и по цели-обёртке `Makefile`/`justfile`/`Taskfile.yml`, которая
  нередко и есть главный вход):

  | Признак в корне | Стек · где искать команду запуска |
  |---|---|
  | `package.json` | Node/JS/TS — `scripts` (dev/start/serve); менеджер по lock-файлу (npm/pnpm/yarn/bun) |
  | `pyproject.toml`, `requirements.txt` | Python — `[project.scripts]`, `uvicorn`/`flask run`/`manage.py runserver` |
  | `go.mod` | Go — `go run ./...` |
  | `Cargo.toml` | Rust — `cargo run` |
  | `Gemfile` | Ruby — `bin/rails server`, `bundle exec` |
  | `pom.xml`, `build.gradle(.kts)` | JVM — `mvn …`, `./gradlew bootRun` |
  | `*.xcodeproj`, `Package.swift` | Apple — Xcode/симулятор, `swift run` |
  | `composer.json` | PHP — `php artisan serve`, `symfony serve` |
  | `docker-compose.yml`, `Procfile` | что за сервисы поднимаются и на каких портах |

- **Тип продукта** (определяет, чем вообще «наблюдать» результат):

  | Тип | Как наблюдать |
  |---|---|
  | Веб-приложение / SPA | браузер на порту из конфига; ищи health-эндпоинт |
  | HTTP API / бэкенд | `curl`/httpie по эндпоинтам; OpenAPI/Swagger, если есть |
  | CLI / скрипт | прогон самой команды с разными флагами и входами |
  | Мобильное | симулятор/эмулятор (iOS Simulator, Android emulator) |
  | Десктоп | запуск окна/бинарника |
  | Бот | тестовый чат/канал |
  | Библиотека | наблюдаемого UI нет: «ручной тест» = примеры использования / REPL / тесты как демонстрация |

## Где искать механизм моков (шаг 5)

- флаги/переменные окружения моков и режимов (ищи в конфиге, `.env.example`, провайдерах/клиентах
  внешних API, тест-хелперах);
- fixture-режимы, feature-флаги, dev/test-only страницы или эндпоинты;
- заранее засеянные «краевые» записи (просроченное, пустое, чужое, максимальный размер).
