# Финал плана

Справочник к шагу 8 скилла create-dev-plan: что сказать человеку в конце — сначала для нового
плана, затем для режима сверки.

> План разработки готов → `docs/tasks/` (<N> задач, доска `board.md`). Посмотри его: порядок
> задают зависимости, первой идёт <T01 …>. Дальше — выполнение по одной задаче:
> `/run-task T01` прогоняет одну задачу через цикл (исполнитель → тестировщик → правки →
> твоя приёмка → коммит), `/build-tasks` делает то же самое подряд по всему плану.
> Сам я разработку не начинаю.

> План сверен со спекой: добавлено <N>, поправлено <M>, заведено на переделку <K>.
> <Если есть pending: «Спека отстаёт по задачам <…> — предлагаю донести туда <что именно>».>
> Дальше — `/build-tasks` или `/run-task <первая новая задача>`.
