# Тихие сроки

Справочник к шагу 5 скилла health-check: что отмирает само, как это проверить и по какому
признаку видна беда.

| Что проверить | Как | Признак беды |
|---|---|---|
| Ключи и токены внешних сервисов | пробный безопасный вызов каждого API из конфига (самый дешёвый метод: список моделей, баланс, `ping`) | 401/403 — ключ истёк или отозван |
| Бесплатные лимиты и квоты | ответ провайдера или его кабинет: сколько осталось на сутки/месяц | 429 и «quota exceeded» — упёрлись в потолок; продукт при этом «работает», но функция мертва |
| Баланс платного провайдера | остаток на счёте, если он виден по API | ушёл в ноль — платная функция отвалилась целиком |
| Сертификат HTTPS домена | срок действия сертификата живого адреса | меньше 2 недель — пора продлевать |
| Домен | дата продления регистрации | ближе месяца — напомни человеку |
| Ответ внешнего API | формат ответа против того, что ждёт код | поле пропало или переименовано — фича сломается молча |
| Спящий бесплатный тариф | первый ответ после простоя | долгий «холодный старт» или проект усыплён |
