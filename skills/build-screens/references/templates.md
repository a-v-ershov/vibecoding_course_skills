# Шаблоны build-screens

Справочник к шагам 7 и 8 скилла build-screens: строки для AGENTS.md проекта и текст финальной
реплики.

## Шаг 7. Строки для AGENTS.md проекта

```
- Данные на экранах — только через слой заглушек (<путь>); прямых запросов к API и базе
  в компонентах нет. Появится бэкенд — меняется слой заглушек, экраны не трогаются.
- Новый экран собирается по docs/spec/04-user-flows.md: все состояния из таблицы
  (пусто, загрузка, ошибка, обычное), тексты — дословно из потока.
- Каждый поток закрыт UI-тестом (<чем>): тест ходит по шагам потока и проверяет все состояния.
  Меняешь экран — правишь поток, потом код, потом тест. Тест упал — чинится экран, а не тест.
```

## Шаг 8. Финальная реплика

> Экраны потока «<имя>» собраны на заглушках → <экраны>; UI-тест зелёный (<чем>, <N> состояний).
> Дальше — живой тест: задания уже в
> `docs/spec/04-user-flows.md` — 3 человека по 15 минут находят то, чего не видит ни автор,
> ни ИИ, ни тест. Следующий поток — `/build-screens «<имя>»`. Когда собраны все потоки, дальше
> по курсу `/create-dev-plan`: он превратит спеку в очередь задач, а бэкенд встанет на место слоя
> заглушек — экраны править не придётся.
