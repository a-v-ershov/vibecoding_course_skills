# CLAUDE.md

Репозиторий плагина Claude Code `vibecoding-course`: 24 скилла курса по
вайб-кодингу (`skills/`, плюс общий справочник формата задач `skills/_shared/`),
три агента (`agents/`: критик спеки, исполнитель задачи, независимый тестировщик),
манифесты плагина и маркетплейса (`.claude-plugin/`).

## Правила скиллов

- **Скиллы переносимы между проектами.** Ничего специфичного для конкретного
  репозитория (домен продукта, его таблицы, его внешние API) в них не попадает:
  стек, команды и сущности скилл определяет из файлов проекта, куда его позвали.
- **Пути внутри плагина** — `skills/_shared/task-format.md` и `agents/<имя>.md`
  «этого плагина», а не `.claude/skills/…`: в установленном плагине их там нет.

## Правила работы с git

- **Не создавать git-веток.** Вся работа ведётся в `main`. Отдельная ветка —
  только если я явно попросил.
- Ничего не коммитить без явной просьбы — я сам говорю, когда коммитить.
